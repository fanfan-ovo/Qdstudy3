本平台面向高校师生，提供 AI 智能答疑服务。本阶段完成前端原型，包含三个页面：

四、HTML5 表单增强特性详解

两个页面尽量使用原生表单校验能力，将数据校验交给浏览器，无需编写 JavaScript。逐项说明：

4.1 required —— 必填校验

所有关键字段必填，未填写时浏览器阻止提交并提示。

<input type="email" name="email" placeholder="请输入邮箱地址" required>

4.2 placeholder —— 占位提示

每个输入框提供灰色占位文字，引导用户正确填写。

<input type="password" name="password" placeholder="请输入密码" required>

4.3 autofocus —— 自动聚焦

页面加载后自动聚焦首个输入框，减少一次点击。

<input type="text" id="username" name="username" required autofocus autocomplete="username">

4.4 autocomplete —— 自动填充

字段autocomplete 值含义
用户名/账号username用户名自动填充
邮箱email邮箱自动填充
手机号tel电话自动填充
登录密码current-password当前密码
注册/确认密码new-password新密码（可触发浏览器强密码建议）

4.5 type="email" —— 邮箱格式校验

<input type="email" id="email" name="email" placeholder="请输入邮箱地址" required autocomplete="email">

4.6 type="tel" + pattern —— 手机号正则校验

type="tel" 在移动端弹出数字键盘；pattern 用正则限制 11 位大陆手机号，title 提供自定义错误提示。

<input type="tel" id="phone" name="phone"
       placeholder="请输入11位手机号"
       pattern="1[3-9][0-9]{9}"
       title="请输入以1开头的11位有效手机号"
       required autocomplete="tel">

4.7 pattern —— 用户名格式校验

<input type="text" id="username" name="username"
       pattern="[A-Za-z0-9]{4,20}"
       title="用户名需为4-20位字母或数字" required>

4.8 minlength —— 密码最小长度

<input type="password" name="password" minlength="6" required autocomplete="new-password">

4.9 select —— 身份下拉选择

用原生下拉框选择「学生/教师」，以 disabled + selected 的空选项强制主动选择。

<select id="role" name="role" required>
  <option value="" disabled selected>请选择您的身份</option>
  <option value="student">学生</option>
  <option value="teacher">教师</option>
</select>

4.10 checkbox —— 记住我

<label class="remember">
  <input type="checkbox" name="remember" value="1" checked> 记住我
</label>

五、其他 HTML5 / CSS3 能力

  1. HTML5 文档类型与语义化：<!DOCTYPE html>、<meta charset>、<label for> 关联输入框。
  2. 响应式 viewport：width=device-width, initial-scale=1.0，卡片 max-width: 94vw 自适应移动端。
  3. CSS3 渐变背景：linear-gradient(135deg, #e0f2fe, #dbeafe, #eff6ff) 浅蓝氛围。
  4. 圆角与阴影：border-radius: 16px、box-shadow 卡片悬浮质感。
  5. 过渡动画：输入框 transition + :focus 蓝色高亮。
  6. accent-color：统一复选框/下拉的品牌蓝。
  7. appearance: none + 内联 SVG data URI：自定义下拉箭头。
  8. ::placeholder 伪元素：统一占位文字颜色。
  9. 无障碍：每个输入框均有 label 关联，鼠标与键盘均可用。
